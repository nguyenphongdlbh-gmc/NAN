KẾT NỐI GOOGLE DRIVE CÁ NHÂN (LƯU TRỮ ĐÁM MÂY VĨNH VIỄN) Chưa kết nối

Tự động upload ảnh & file ghi âm lên thư mục BienHoa_SmartTourism3D_Media trên Google Drive của bạn và lấy link chia sẻ vĩnh viễn.

Hướng dẫn 3 bước lấy Google Client ID miễn phí để lưu file trực tiếp vào Google Drive riêng:
1. Truy cập console.cloud.google.com → Tạo dự án mới → Bật Google Drive API.
2. Vào mục Credentials (Thông tin xác thực) → Tạo OAuth 2.0 Client ID (Loại: Web application) → Thêm địa chỉ trang web hiện tại vào Authorized JavaScript origins.
3. Dán mã ...apps.googleusercontent.com vào ô trên và nhấn Kết nối Google Drive. Mọi ảnh & file ghi âm upload sẽ tự động lưu vào Drive của bạn!
